# SDMULE.DEV Portfolio

Personal portfolio for Saurabh Mule, built as a static React application with Vite and Material UI.

## Development

```sh
npm install
npm run dev
```

## Build and checks

```sh
npm run lint
npm run build
```

For Netlify, use `npm run build` as the build command and `dist` as the publish directory.

## Resume

The original resume is served directly from `public/Saurabh Mule.pdf`; the portfolio links to that file for viewing and downloading.

## Portfolio content

Profile details, experience, skills, hobbies, education, contact links, and project case studies are maintained in `src/data/portfolio.js`.
